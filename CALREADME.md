- I combined all of my knowledge of API's, databases, controllers, fetching data, async and await, and for each loops to create a complete cafe website. Creating 3 seperate data bases and then calling them for the js was definately challenging, but I found this project to be a lot of fun overall. I struggled to find a way to get the categories to show up on the screen then sort each card under each category, but I solved it with a foreach loop inside of a foreach loop. One for each loop generated the title, while another generated each card and only displayed the one that matched the specific category. It would probably have been more efficient to sort through the database each time instead of going through the whole database, but that is how I decided to solve it. Trying to figuring out flex boxes and grids was a pain the the butt, but I got it done and feel more confident with the two because of it.
